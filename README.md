# Saep Simulado

Etapa 1:
requisitos funcionais:
1. Autenticar Usuarios
2. Cadastrar Usuarios
3. Registrar chamados ligados aos equipamentos da empresa.

Requisito não funcional:
Todo usuário deve ter nome, e-mail único e senha armazenada de forma protegida.
Todo chamado deve apresentar um equipamento, uma descrição, uma prioridade (Baixa, Média ou Alta) e um status inicial “Aberto”.
O sistema não deve permitir criar um chamado para um equipamento inexistente.
